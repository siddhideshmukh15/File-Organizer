# File Organizer

## Description
A simple Python application that automatically organizes 
files into different folders based on their file extensions.

## Features
- Organizes images, documents, videos, and music.
- Creates folders automatically.
- Moves files into suitable folders.
- Stores unsupported files in the Others folder.
- Skips duplicate filenames.

## Technologies Used
- Python 3

## Concepts Learned
- File handling
- Dictionaries
- Loops and conditional statements
  

## Future Improvements
- Add more file categories.
- Organize files by date.
- Add an undo feature.
