# File Organizer

## Description
A Python-based application that automatically organizes files into different folders based on their extensions. It includes a preview option so users can check file destinations before organizing.

## Features
- Organizes images, documents, videos, and music.
- Creates folders automatically.
- Previews file movements before organizing.
- Asks for confirmation before moving files.
- Allows users to cancel the operation.
- Skips duplicate filenames.
- Stores unsupported files in the Others folder.
